# SQLAlchemy: server_default vs onupdate vs func

This document explains the differences between `server_default`, `onupdate`, and `func` in SQLAlchemy models, as used in your `Project` model.

## 1. `func`
`func` is a special object in SQLAlchemy that allows you to call **SQL functions** that are defined in your database (like `NOW()`, `CURRENT_TIMESTAMP`, `uuid_generate_v4()`, etc.).

- **How it works**: When you use `func.now()`, SQLAlchemy doesn't execute anything in Python. Instead, it generates the SQL equivalent (e.g., `CURRENT_TIMESTAMP`) to be executed by the database server.
- **Example**: `created_at = Column(DateTime, default=func.now())`

## 2. `server_default`
`server_default` tells SQLAlchemy to set a default value at the **database schema level** (inside the `CREATE TABLE` statement).

- **Execution**: The value is generated by the **Database Server** when a row is inserted.
- **Advantage**: Even if someone inserts data into the database manually (not through your Python app), the default value will still be applied.
- **Common use**: `server_default=func.now()` creates a column with `DEFAULT CURRENT_TIMESTAMP` in SQL.

## 3. `onupdate`
`onupdate` is used to automatically update a column's value whenever the row is **modified/updated**.

- **Execution**: This is typically handled by SQLAlchemy when it issues an `UPDATE` statement.
- **Common use**: Tracking when a record was last modified.
- **Example**: `updated_at = Column(DateTime, onupdate=func.now())`

---

### Comparison Table

| Feature | `default` | `server_default` | `onupdate` |
| :--- | :--- | :--- | :--- |
| **Where it runs** | Python side (SQLAlchemy) | Database side (Schema) | Python side (during Update) |
| **When it runs** | During `INSERT` | During `INSERT` | During `UPDATE` |
| **Visible in DB?** | No (only in code) | Yes (as `DEFAULT` value) | No (only in code) |

### In your code:
```python
# Set by DB once when project is created
created_at = Column(DateTime(timezone=True), server_default=func.now())

# Set by SQLAlchemy every time project is updated
updated_at = Column(DateTime(timezone=True), onupdate=func.now())
```
